Plataforma web de gestión escolar — Asistencia, calificaciones, horarios y comunicados con acceso por roles.

🔐 Iniciar Sesión (Demo) 📂 Ver Código en GitHub

📋 Características

🎭 5 Roles de Usuario

Admin, secretaría, docente, estudiante y padre con permisos y paletas visuales distintas.

✅ Asistencia Digital

Registro de presencia, faltas, retrasos y licencias con notificaciones automáticas.

📚 Calificaciones

Notas por materia y trimestre con cálculo de promedio y libreta académica imprimible.

🕒 Horarios

Vistas adaptativas de horario según el rol del usuario.

📢 Comunicados

Avisos segmentados global, por curso, docente o área.

🔐 Seguridad

Hash PBKDF2-SHA256, CSRF, rate-limiting y auditoría de accesos.

⚠️ Esta es una versión demo estática para GitHub Pages. El sistema completo con PHP y MySQL requiere un servidor como XAMPP. Consulta README_INSTALACION.md para la instalación local.
